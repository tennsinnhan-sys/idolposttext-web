# IdolPostText Web

推し活イベント用の投稿テキストを生成するアプリのWeb版です。メンバー情報などはCloudflare（Worker + D1データベース）で全員に共有され、それ以外（今の選択状態など）はブラウザごとの個人用データとして保存されます。

このアプリは2つのプロジェクトのセットで動きます。

- **idolposttext-web**（このフォルダ）：画面（フロントエンド）
- **idolposttext-api**（別フォルダでお渡し）：データを保存するAPI（Cloudflare Worker + D1）

先に `idolposttext-api` 側のセットアップを終わらせてから、こちらに進んでください。

## 1. `.env` を設定する

`idolposttext-api` のセットアップで発行されたWorkerのURL（例：`https://idolposttext-api.your-subdomain.workers.dev`）を使います。

1. このフォルダ直下に `.env.example` をコピーして `.env` という名前で保存
2. 中身をWorkerのURLに書き換える

```
VITE_API_BASE_URL=https://idolposttext-api.your-subdomain.workers.dev
```

## 2. ローカルで動かす

```bash
npm install
npm run dev
```

表示されたURL（例：`http://localhost:5173`）をブラウザで開いて動作確認してください。

## 3. インターネットに公開する（Cloudflare Pagesの例）

1. このプロジェクトのフォルダをGitHubリポジトリにアップロード
2. https://dash.cloudflare.com にアクセスし、「Workers & Pages」→「Pages」→「Create」→「Connect to Git」
3. アップロードしたリポジトリを選択
4. ビルド設定
   - Build command: `npm run build`
   - Build output directory: `dist`
5. 「Environment variables」に `.env` と同じ内容（`VITE_API_BASE_URL`）を追加
6. 「Save and Deploy」を押すと数十秒〜数分で公開され、`https://（プロジェクト名）.pages.dev` のようなURLが発行されます

## 4. iPhoneのホーム画面に追加する

公開したURLをSafariで開き、共有ボタン→「ホーム画面に追加」。

## データの持ち方まとめ

| データ | 保存場所 | 共有範囲 |
|---|---|---|
| メンバー情報・イベント情報・テンプレート・投稿履歴・グループの表示/非表示 | Cloudflare D1（Worker経由） | 全員で共有（5秒おきに自動更新） |
| グループのレギュレーション・読み方・現在の選択状態（プレビュー） | このブラウザ（localStorage） | 個人用（他端末には同期されません） |

個人用データはブラウザ・端末ごとなので、PCとiPhoneの間では共有されません。アプリ内の「データを書き出す／読み込む」機能で手動で移すことができます。

## 共有の仕組みについて（重要）

- メンバー情報などは、リンクを知っている人なら誰でも編集・削除できる設定になっています（ログイン機能は付けていません）
- 他端末の変更は**5秒おきの自動更新**で反映されます。Supabase版で使っていた「即時反映」ではなくなりましたが、体感の差はほとんどありません
- 自分がたった今保存した内容は、直後の自動更新では上書きされないようになっています（保存してから4秒間は、その項目だけ自動更新をスキップします）

## オフライン対応について

- アプリの画面自体は一度開けば端末にキャッシュされ、電波が無い状態でもすぐに開けます（PWA対応）
- メンバー・イベント・テンプレート・履歴も、前回読み込んだ内容がそのまま表示されます（閲覧・コピーはオフラインでも可能）
- オフライン中に新規登録・編集した内容は、いったん端末には保存されますが、通信が回復するまでは他の端末には反映されません。通信が回復すると自動で再送されますが、他の人が同じ内容を先に編集していた場合は上書きされる可能性があります
